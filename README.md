# Pet Projects

A selection of projects across various areas of the IT sector.

## Bachelor's graduation work

Разработка веб-приложения для планирования программ питания и тренировок. Проект включает в себя профили пользователей, распорядок дня, расчёт калорий и соотношения углеводов, белков и жиров, программы питания, программы тренировок и дневники тренировок. Разработано с использованием PHP, CakePHP, JS, CSS, HTML.

## Computer Networks

Лабораторные работы по компьютерным сетям. Настройка и исследование сетевого взаимодействия, изучение принципов работы компьютерных сетей и сетевых протоколов.

## Database development for a barbershop

Разработка базы данных для автоматизации работы парикмахерской. Проектирование логической и физической структуры базы данных, создание таблиц, связей, процедур и триггеров. Работа с SQL и реляционными базами данных.

## Development of a class library

Разработка библиотеки классов для инвентаризации предприятия. Знакомство с объектно-ориентированным программированием на C++, разработка классов и взаимодействия между ними.

## Graduation work for the Department of Additional Education

Разработка веб-приложения для организации дополнительного образования. Реализация системы управления командами, пользователями и учебными задачами. Работа с PHP, базой данных, веб-интерфейсом и серверной частью приложения.

## Introduction to Machine Learning

Изучение основных методов машинного обучения на Python. Разбор разведочного анализа данных и линейной регрессии, метода k-ближайших соседей, метода опорных векторов, градиентного спуска, а также решение задач классификации и прогнозирования.

## Introduction to the basics of AI

Изучение основных методов искусственного интеллекта и машинного обучения. Реализация классификатора методом k-ближайших соседей, логистической регрессии, ансамблей моделей на основе решающих деревьев и кластеризации K-means. Знакомство с PyTorch и распознаванием рукописных цифр.

## graph_plotter

Разработка приложения для построения математических графиков. Реализация графического интерфейса и построения графиков функций на Python.

## other sql expirience

Дополнительные практические работы с SQL. Изучение оптимизации запросов, транзакций, представлений и разграничения прав пользователей в реляционных базах данных.
